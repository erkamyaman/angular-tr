## Hakkında

Bu repo, Angular'ın resmi dokümantasyonunun (`adev`) Türkçe çevirisini barındırır. Derlenen site [angular-docs.tr](https://angular-docs.tr/) adresinde yayınlanır ve Angular'ın resmi Topluluk Çevirileri (Community Translations) listesinde yer alır.

- **Güncel sürüm:** Angular **v22**
- **Kaynak:** `adev/src/content` altındaki resmi Angular dokümantasyonu
- **Amaç:** Türkçe dokümantasyonu her Angular sürümüyle güncel tutmak
