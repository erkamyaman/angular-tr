# Kullanılmayan `@let` bildirimi

Bu tanılama, değeri şablonda hiç okunmayan `@let` bildirimlerini tespit eder.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `
    @let fullName = user.firstName + ' ' + user.lastName;
    <h1>Hoş geldiniz</h1>
  `,
})
class MyComponent {
  user = {firstName: 'Ada', lastName: 'Lovelace'};
}
```

## Bunda ne yanlış?

Kullanılmayan bir `@let` genellikle bir yeniden düzenlemeden kalmıştır veya değerin kullanılması gereken bir yere işaret eder.
Angular, kullanılmayan bir `@let` ifadesini şablon her güncellendiğinde yine de değerlendirir. Örneğin, ifadedeki bir fonksiyon çağrısı yine de çalışır.

## Bunun yerine ne yapmalıyım?

Bildirimi ya kullanın ya da kaldırın:

```angular-ts {prefer, header: "bildirimi kullanın"}
@Component({
  template: `
    @let fullName = user.firstName + ' ' + user.lastName;
    <h1>Hoş geldiniz, {{ fullName }}</h1>
  `,
})
class MyComponent {
  user = {firstName: 'Ada', lastName: 'Lovelace'};
}
```

```angular-ts {prefer, header: "bildirimi kaldırın"}
@Component({
  template: `<h1>Hoş geldiniz</h1>`,
})
class MyComponent {}
```

## Bunu önleyemezsem ne olur?

Bu tanılama, projenin `tsconfig.json` dosyası düzenlenerek devre dışı bırakılabilir:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "unusedLetDeclaration": "suppress"
      }
    }
  }
}
```

Daha fazla bilgi için [genişletilmiş tanılama yapılandırması](extended-diagnostics#yapılandırma) bölümüne bakın.
