# Fonksiyonlar olay bağlamalarında çağrılmalıdır.

Bu tanılama, olay bağlamalarında çağrılmamış fonksiyonları tespit eder.

<!-- prettier-ignore -->
```angular-ts
import {Component, signal, Signal} from '@angular/core';

@Component({
  template: `<button (click)="onClick">Click me</button>`,
})
class MyComponent {
  onClick() {
    console.log('clicked');
  }
}
```

## Bunda ne yanlış? {#whats-wrong-with-that}

Olay bağlamalarındaki fonksiyonlar, olay tetiklendiğinde çağrılmalıdır.
Fonksiyon çağrılmazsa, olay tetiklendiğinde çalışmaz.

## Bunun yerine ne yapmalıyım? {#what-should-i-do-instead}

Olay tetiklendiğinde fonksiyonun çalışması için bir olay bağlamasında kullandığınızda fonksiyonu çağırdığınızdan emin olun.

```angular-ts
import {Component} from '@angular/core';

@Component({
  template: `<button (click)="onClick()">Click me</button>`,
})
class MyComponent {
  onClick() {
    console.log('clicked');
  }
}
```

## Yapılandırma gereksinimleri {#configuration-requirements}

Herhangi bir genişletilmiş tanılamanın verilmesi için [`strictTemplates`](tools/cli/template-typecheck#katı-mod) etkinleştirilmelidir.
`uninvokedFunctionInEventBinding`, `strictTemplates` dışında ek bir gereksinime sahip değildir.

## Bunu önleyemezsem ne olur? {#what-if-i-cant-avoid-this}

Bu tanılama, projenin `tsconfig.json` dosyası düzenlenerek devre dışı bırakılabilir:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "uninvokedFunctionInEventBinding": "suppress"
      }
    }
  }
}
```

Daha fazla bilgi için [genişletilmiş tanılama yapılandırması](extended-diagnostics#yapılandırma) bölümüne bakın.
